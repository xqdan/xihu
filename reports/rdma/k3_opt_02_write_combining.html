当前问题

当前 wire bytes 约 24.4 MiB，但 request 数达到 33,201；B=1 下每个 payload 较小，固定 header、flag、commit 和 ACK 比例较高。

现状建议扫描值影响
stripe16 KiB当前基线
stripe32/64 KiB减少 packet/notification 次数
payload逐 partial 写入多个 partial 先合并再写
commit逐 phase按 layer/group 批量 commit
ACK逐 rank/phase按 group 或 bitmap ACK

实现注意

  • 合并写入不能破坏不同 rank 的 slot 所有权。
  • 必须保留 epoch、长度、校验和和 ready bitmap。
  • 不能为了聚合而等待过久，否则会增加计算端 stall。

推荐参数

stripeKiB=32stripeKiB=64writeCombineWindow=1～2 μs
