4. RDMA 内存语义与生命周期

RDMA one-sided write → remote SRAM slot visibility → commit / ready counter → partial-ready acquire → reduce / direct consumer → group ACK → partial release → epoch reuse

RDMA 不被视为零成本。模型保留远端 SRAM 写入可见性、commit、ready counter、partial-ready acquire、reduce、group ACK、partial release 和 epoch reuse。LSE 归约仍使用 m/l/O online-softmax 语义，不按普通 FP32 sum 处理。

8. 剩余缺口与后续验证

剩余缺口：当前 raw latency 比目标预算高约 -26.11 μs。Shared SRAM 聚合工作窗口余量约 0.13 MiB/卡，整卡功耗余量约 158.78 W。该候选还使用 640 GB/s/MC 的 Stretch 假设；参考 MC 的 320 GB/s 点约为 584.75 TPS/usr。
  • 验证 partial-ready threshold 的真实硬件粒度和乱序到达行为；
  • 验证 TMA 独立端口和 bank partition 的物理布线、冲突率与时序；
  • 将 group ACK/ready counter 做成 RTL 级 credit/timeout 模型；
  • 校准 Attention、MoE token packing 和 Wup/router fusion 的真实 kernel trace；
  • 冻结可制造的 MC 带宽与卡内/跨卡物理拓扑；
  • 对 1000 TPS 目标做多 seed 搜索，避免把单个搜索结果误解为全空间上界。
