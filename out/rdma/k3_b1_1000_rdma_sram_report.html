1. 建模的内存语义生命周期

remote SRAM address → one-sided write → SRAM visibility/commit → ready notification → consumer acquire/read/reduce → ACK → epoch release

WRITE 不等于 READY；只有远端 SRAM 写入完成、commit/visibility 生效、ready 可见后，消费者才 acquire。消费者完成读取/归约后返回 ACK，所有 rank ACK 后 slot 才能按 epoch release，避免 ABA、重复写和提前复用。RDMA 仍受 issue、wire serialization、接收 SRAM 写口、NoC、reduce、WQE/CQE credit 与通知/ACK 延迟约束。

当前瓶颈主要是 kernel、local TMA/端口以及 RDMA memory transport；direct-to-SRAM 消除了传统 collective 的部分额外拷贝/启动，但没有消除远端写可见性、ACK、卡内 Die 合并和 SRAM/NoC/reduce 资源竞争。若继续冲击 1000，应建模通信融合、批量 commit/notification、更多计算-通信重叠或减少同步 epoch，而不是把 RDMA 视为零成本。
