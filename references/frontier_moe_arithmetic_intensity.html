I 怎么从 Decode 变到 Prefill

I_MC
I_MC = FLOP / HBM，不含网。高→算力墙，低→带宽墙。 定 H 用 Prefill 整模 I_MC = [(线性+注意力)/(TP·CP)] / (权重/TP + KV/CP)。 I+网 = FLOP / (HBM + 2(TP−1)·payload·tokens + 2(CP−1)/CP·KV)，更稀，不定档。
线性 GEMM
Decode I = 2×参数 / 权重字节（MXFP4 Routed ≈ 3.76，BF16 = 1）。Prefill 每卡仍读一份权重、FLOP ×本地 token，所以 I ×(S/CP)。CP=1 时就是 ×S。
挂核
PD 同时：L 跑 Decode，H 跑 Prefill。Decode 矩阵尽量挂 L；若该算子 I 高于「PD 下 L 脊点」= L脊点/Decode份额，则临时上 H。Prefill 矩阵始终挂 H。伴随 Vector 跟矩阵走。
PD 带宽
L 与 H 共用 3.58 TB/s，按 Decode / Prefill 份额调度，不是各吃满带宽。份额下有效脊点 = 原脊点 / 份额。Vector 匹配 TF = I × (份额×3.58) / 0.8。
因果稠密注意力
MLA / HCA / indexer：Decode I 与 L 无关，矩阵核挂 L。Prefill 因果积分 FLOP ~ S²、写出 KV ~ S，I ≈ (S/2)×Decode，矩阵核挂 H。Softmax/LSE 走 Vector。
MLA / MQA 怎么切
潜变量 KV 跨头共享（V4 还是 MQA），不能按头切 KV。TP 只切 Q 头：FLOP ÷TP，每卡仍读完整 KV，所以算子 I ÷TP。要摊 KV 容量和本步 KV 带宽只能走 CP（切序列）：Prefill FLOP 与本地 KV 同 ÷CP，MC I 不变。引擎里「MLA CP=TP」指的就是用 TP 组做 Context 分片，不是切头。
固定工作集
DSA/CSA topk、滑动窗：Prefill I ≈ Decode I，Decode 仍挂 L、Prefill 仍挂 H。KDA / RMSNorm / SiLU / RoPE / Softmax / 残差是 Vector，I 几乎不随 S、B 变，不改挂 L/H。
Vector
逐元素与非线性：RMSNorm、残差 Add、SiLU 跟线性走；RoPE、Softmax/LSE 跟注意力走；KDA 留在 Decode 的 L（I 低，不溢出）。PD 并行时 L-Vector 喂 Decode，H-Vector 喂 Prefill；注意力溢出到 H 时 Softmax/RoPE 也上 H，H-Vector 按两路叠加。相对 MC 多在带宽墙；融合进矩阵核时不另占 MC。
Decode batch
B = 同一 replica 并发序列。稠密权重读 1 份、FLOP ×B，I ×B。Routed 独特专家 ≈ E·(1−((E−k)/E)B)，字节随独特集合涨，I ≈ I₁·B·k/uniq，碰撞少时几乎不涨。注意力与 KDA：FLOP 和状态都 ×B，I 不变。
TP
稠密权重全分片：GEMM 的 FLOP 和权重同 ÷TP，线性算子 I 不变。MLA/MQA 核不同：只切头、KV 复制，注意力 I ÷TP。环 all-reduce 导线 = 2(TP−1)·payload；Decode ×B，Prefill payload ×(S/CP)。Decode TP=1 / 8 / 16；Prefill 另加 TP32。三模型头数均可整除。
CP
切序列 / KV。每卡 s=S/CP：线性 I ×s；MLA 注意力 I 不随 CP。导线 2(CP−1)/CP · KV。Prefill CP=1 / 8 / 16 / 32。
预取 (2−p)
只放大 Decode Routed 分母。Prefill 按 p=1 读一份专家。

各算子怎么切，I 怎么变

三条轴：TP 切张量（头或列），CP 切序列 / KV，EP 放专家。 强度只在「FLOP 和字节不同步 ÷」时才变。下面公式是算子 MC I；计入导线后的整模 I+网更稀，见 Prefill / Decode 表。

I 随切分怎么走

线性 GEMM：FLOP 与权重同 ÷TP，I(TP)=I₁ 不变。Prefill 每卡读一份权重、本地 s=S/CP，I(CP)=I₁·S/CP。Decode 稠密 I(B)=I₁·B；Routed 按独特专家，B 增大时 I 几乎不涨。

MLA / MQA 核：KV 不按头切。TP 切 Q 头，I(TP)=I₁/TP。CP 切序列，FLOP 与本地 KV 同 ÷CP，MC I(CP)=I₁。Prefill 因果核再乘长度：I=I₁·S/(2·TP)（topk/窗不乘 S）。

Vector：I(TP,CP,B,S)≈I₁。KDA 状态不随 L，CP 摊不掉。

I_MC vs I+网：I_MC = [(线性+注意力)/(TP·CP)] / (权重/TP + KV/CP)。 I+网 = FLOP / (HBM + 2(TP−1)·payload·tokens + 2(CP−1)/CP·KV)，不定档。

Decode Roofline

一步 Decode，并发序列 B=1 / 16 / 32，切分 TP=1 / 8 / 16。矩阵核默认挂 L；I 高于 PD 下 L 脊点时临时上 H（H 同时在跑 Prefill）。 MLA/MQA 核 I÷TP。圆 = B=1，方 = B=16，菱 = B=32。注意力 I 不随 B。 Vector 见 算子表 与 L/H 分核需求。下表另给计入集合通信导线后的整模 I。

L-Core

Decode 留在 L 的矩阵。线性：圆 B=1，方 B=16，菱 B=32。注意力 I≤PD 下 L 脊点才出现（加大 TP 常回到 L）。

H-Core

Decode 溢出到 H 的注意力（I 高于 PD 下 L 脊点）。H 同时跑 Prefill，矩阵峰值不叠加两份，是抢占/分时。Softmax 见 Vector。

Decode 整模 I × TP（MC vs 计入导线）

Prefill Roofline

一条 Prefill 序列，切分 TP=1 / 8 / 16 / 32 与 CP=1 / 8 / 16 / 32。矩阵核（线性 + 注意力）都挂 H-Core，L 图空。 线性算子 I ×(S/CP)，空心方/菱/倒三角 = CP8/16/32。 MLA/MQA 实心圆/方/菱/倒三角 = TP1/8/16/32：切头则 I÷TP，KV 不切；CP 不改变这些核的 MC I。 整模 I+网：实心=纯 TP（CP=1），空心同形=纯 CP（TP=1），五边形=TP=CP。Vector 见独立表。

L-Core

Prefill 不挂 L。本图空。L 留给 Decode。

H-Core

Prefill 全部矩阵核。线性：实心圆 CP1，空心方/菱/倒三角 CP8/16/32（I×S/CP）。MLA/MQA：实心圆/方/菱/倒三角 = TP1/8/16/32（I÷TP）。整模 I+网：空心同形 = 纯 CP；五边形 = TP=CP。

Prefill 整模 I × TP × CP

Vector 算子

RMSNorm、残差、SiLU 跟线性；RoPE、Softmax/LSE 跟注意力；KDA 留在 Decode 的 L。 I 几乎不随 B、S。墙相对各核自己的 Vector 脊点（用该核分到的带宽），见 PD 分核表。

PD 并行 · L / H 各自的 Vector

L 跑 Decode、H 跑 Prefill，MC 按上面的 Decode 份额切开。 Vector 匹配 TF = I × (份额 × 3.58 TB/s) / 0.8。 Decode 注意力 I 高于「L 脊点 / 份额」时临时上 H，RoPE / Softmax 跟着走；H-Vector 按 Prefill 路 + 溢出 Decode 路叠加（同核 ALU 同时伺候两路）。 矩阵峰值仍不叠加：溢出时 H 在 Prefill 上抢占一段时间给 Decode。

按算术强度重定 L / H 算力

带宽不动：16×320 GB/s×0.7 = 3.58 TB/s，利用率 0.8。 F_match = I × 3.58 / 0.8，再上取到 Tensor 档。 L：Decode 稠密 I×B（B≤32）。H：max(Decode 注意力, Prefill 32×32 整模 I_MC)，能大尽量大 → 8388 TF。 I+网 / 8×8 / 注意力÷TP 只对照。

I_MC 要点

1. 定义　I_MC = FLOP / HBM。不含网。高→算力墙，低→带宽墙。

2. 定 H 用整模　I_MC = [(线性+注意力)/(TP·CP)] / (权重/TP + KV/CP)。不是算子 I×S。

3. TP 摊不掉线性 I　FLOP 和权重同 ÷TP。只有 CP 摊：每卡 s=S/CP，线性 I ×s。

4. 所以 32×32 仍 ~2k　s=32K/32=1024，I_MC≈2k，F = I_MC × 3.58 / 0.8 → 8388 TF。 I+网 = FLOP / (HBM + 2(TP−1)·payload·s + 2(CP−1)/CP·KV)，更稀，不定档。
