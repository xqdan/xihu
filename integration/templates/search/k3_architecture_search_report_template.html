1. 双目标结果与 Pareto 前沿

蓝灰点：所有已评估可行方案；紫线：非支配前沿（连线仅帮助阅读，不代表可连续插值）；橙点：所选两端及折中方案。折中定义 max min(F1/F1_best, F2/F2_best)，不把量纲不同的 TPS 直接相加。

前沿是“硬件 + 固定软件配置”的联合候选前沿。本轮同一个候选在 B=1/B=32 使用相同 KV/head tile、预测深度与窗口比例；尚未对两个 batch 独立挑选 kernel 配置或搜索 DMA 限流。因此较低链路速率的候选吞吐更高，可能是不可抢占预测 DMA 的排队效应，不代表降低物理带宽天然更好。最终定版前应对这些硬件候选再做按 batch 独立调度与限流优化，不能仅凭本图认定硬件的绝对最优速率。

TP=32 的一个 rank 是一整卡，32 卡共同执行同一个模型副本。B=32 的整体 TPS 为 32×单序列 TPS，不再乘 TP32。Die→MC 直连；卡内 ring 的保守单向 bisection 预算=2×单链路有效带宽，不能用 8 Die 注入之和代替。32 卡网络按每 rank 800 GB/s 有效注入上限建模，不假设服务器交换网络无限带宽。

3. 所选候选：容量、带宽、时延与物理预算

SRAM 层级与最大对象需求

卡级 shared pool 只包含 8×Shared SRAM×85% 可用率，再乘调度窗口比例；所有 local SRAM 均不计入该池。本模型假设 shared 对象按容量均匀条带化；单 Die 的局部热点/最坏 bank 偏斜没有路由级验证。H-local 容量按整个 B×KV tile 的分片计算，不能以小 batch tile 代替却仍宣称 KV 只装载一次。

仅两端与折中候选保存完整 93 层分解；其他 Pareto 候选保存汇总。服务时间不含外存数据未到齐等待；模拟器另外计入该等待和排空，并满足 raw time = compute + collective + exposed wait。

5. 从物理参数到算子与 TPS：程序实际使用的公式

F1 = 1e6 / (T_step(B=1) × 1.17) [TPS/usr] F2 = 32e6 / (T_step(B=32) × 1.17) [aggregate tok/s] 矩阵峰值 / Die = N_core × N_engine × rows × cols × 2 × GHz / 1000 [TFLOPS] L fill = min(1, M_effective / L_rows) dense M_effective=B；routed M_effective=B×topK/U；U=min(896,16B) H fill = min(1, head_tile / H_rows) × min(1, token_per_core / H_cols) PV 的 N 使用 512；linear recurrent 使用 M=1 且 active_core≤3B T_kernel = 1.15 × max(FLOPs/effective_compute, local_read/BW, local_write/BW, unpack_time) T_shared_to_local = TMA_setup + NoC_latency + max(bytes/NoC, bytes/shared_read, bytes/TMA, bytes/local_write) T_local_pipeline ≥ (matrix/vector stores + TMA fills) / local_write_BW T_op = T_kernel + 未被本地分块流水隐藏的 TMA + output_flush + reduce + die_link + launch T_step = 93 层依赖时间线 + 最后 norm/LM/sampling + 首次启动/最终排空 DMA 与算子重叠，shared 端口与 NoC 预算按当前算子的平均流量扣除。
模块落实的行为与限制
Core 局部 SRAML 核保留双缓冲权重分片、激活/输出与 64 KiB 控制工作区；H 核保留双 KV slab、FP32 双 score、O accumulator、Q 与控制区。local 容量不足直接淘汰，而不是借用所有卡级 SRAM 掩盖。
Attention每 rank 负责 context/32，但计算全部 96 query heads。卡内按 sequence/token 分给 H cores；同一 KV tile 跨 head tile 本地复用。每个 PV tile 的 FP32 m/l/O partial 显式写回 shared，由 reduce 合并；B<8 的跨 Die partial 额外走 UCIe。
Vector / unpack每核 vectorLanes×2 等效 op/cycle；Vector/SFU 利用率 35%。解量化由 L-core Vector 输入路径处理，不假设可无限速解码。BF16 matrix peak；路由权重仍按 17/32 byte 存储。
NoC / TMANoC 采用 mesh cut 服务包络，带宽随 link width、平行 lane 和频率变化；时延按 mesh 边长×2 cycle/hop。TMA 每核有数量与 B/cycle，16-cycle setup。不是逐 packet、VC 或仲裁仿真。
MC / UCIe16 MC 每颗 8 GB，总 128 GB；内存名义带宽×70%，MC UCIe 有效 lane 带宽×80%。考虑 12.5% 远端 spill/rebalance 的环 cut 预算；DMA 启动时间折算为平均事务有效带宽，不是逐条事务精确延迟。
RDMA / collectives每 Die 有 RDMA lane；每 lane 名义112 Gbit/s，有效75%。32 rank all-gather 使用5 step、31/32×payload；其他归约按保守10 step、2×31/32×payload。每 step 0.14 μs。另计卡内合并/Shared reduce；LSE 的非线性归约语义仍是服务时间近似。
SRAM/DMA 生命周期继承事件模拟器：读对象分配→搬移→就绪→消费者完成→释放；预测错误与淘汰分别记账；一条不可抢占聚合 DMA lane；与计算/通信重叠。预测正确率80%，可搜索D=0/1/2/4。
物理面积/功耗矩阵、Vector、SRAM、bank、core、TMA、NoC、reduce、UCIe、RDMA 和控制分别求和。频率提高按 f^1.2 叠加到计算动态功耗；不是 PDK voltage/frequency 模型。I/O 按峰值流量预算。

7. 结果边界与复算

不能把上述 TPS 作为真实 K3 的性能承诺。当前模型比卡级“总 SRAM + 总带宽”模型更细，但仍是分层服务包络 + 离散事件缓存模型。它用于筛选下一轮值得做 RTL/NoC/PDK/封装验证的候选，而不是签核。
与上一份 SRAM–TPS HTML 的区别：上次只约束卡级聚合 SRAM 与固定有效算力；本次加入小 batch 的矩阵行填充、local/shared 分离、shared→local TMA 搬移、局部端口争用、shared reduce 与多级互联。因此 TPS 不能直接拿两份报告做“同一硬件的误差”对比。尤其 Shared SRAM/卡不等于总 SRAM/卡：本次的总量还包含所有 L/H core 的本地 SRAM。
  1. 项目 K3 preset：93 层、24 Softmax/69 Linear、92 MoE、hidden7168、896 experts/top16、latent3584、expert3072、2 shared experts；layer0 无 FFN。投影参数按 residual budget 的60%/40%拟合；未知真实层序、真实投影形状会改变优选硬件。
  2. 仅 decode、1M context、固定32 rank；B=1 与 B=32 是不同工作负载。没有 prefill、动态 batching、KV prefix reuse 或跨 token 权重常驻。两个目标共享同一硬件与本次搜索的软件参数。
  3. 层间和全局算子流串行，仅本地分块与外存 DMA 可重叠；L/H 跨算子并行、pipeline collective、MoE 热点、RF 压力与路由抖动未全面建模。
  4. 局部算子工作分片按均衡处理，以1.15时间/局部容量系数留余量；shared池按均匀条带化。没有完整 per-core/per-bank 调度、mesh link-by-link拥塞、时钟收敛或 PHY SI/PI 验证。独立 ring/reduce 服务约束尚未实现与背景 DMA 的包级共享仲裁。
  5. H core 矩阵 rows 可以很小，这是搜索中的物理微架构选择，不是凭空把64行阵列的空闲行利用起来。L矩阵拟合投影未知 N/K 维度，因此没有可靠的逐列填充模型，需真实权重形状校准。
  6. 本地 SRAM bitcell 密度1.26 MiB/mm²参考旧概念文档；更宽端口另计bank成本。其余多为工程假设；MC面积暂固定100 mm²，带宽加大主要通过功耗/PHY计价，未实现DRAM堆叠/封装价格模型。板级2400 W限额是设计预算，不代表现成PCIe卡规格。
  7. 有限随机初始化 + Pareto精英交叉/变异 + 端点/折中的逐坐标邻域搜索，固定seed可复现；不穷举庞大离散空间，不保证全局最优或收敛。相同性能的选择优先面积更小、其次功耗更低。可以增加样本/代数或替换成本系数继续搜索。
